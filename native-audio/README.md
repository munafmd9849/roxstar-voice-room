Native Oboe / C++ audio lives with the Android app:

- `android-app/app/src/main/cpp/recorder.cpp` — Oboe input stream
- `android-app/app/src/main/cpp/echo_processor.cpp` — delay-line echo
- `android-app/app/src/main/cpp/wav_writer.cpp` — mono 16-bit WAV
- `android-app/app/src/main/cpp/jni_bridge.cpp` — Kotlin JNI boundary
